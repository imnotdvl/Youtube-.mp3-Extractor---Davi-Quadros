# Youtube Extractor - Davi Quadros

Este projeto permite extrair áudio .mp3 de vídeos do YouTube usando Node.js e yt-dlp.

## 💡 Como rodar na sua casa

### 1. Pré-requisitos
Você precisará ter instalado:
* **Node.js**
* **yt-dlp** (ferramenta de linha de comando para baixar vídeos)
* **FFmpeg** (necessário para a conversão de áudio)

### 2. Instalação
Clone este repositório ou baixe os arquivos. Abra o terminal na pasta do projeto e rode:
```bash
npm install
